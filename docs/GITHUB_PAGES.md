# Publicação no GitHub Pages

## Preparação

- O projeto é estático (HTML/CSS/JS).
- Caminhos relativos são usados para assets e módulos.
- Web Worker carregado via `js/lab-worker.js`.

## Passos

1. Criar repositório.
2. Enviar arquivos da pasta do projeto.
3. Ativar GitHub Pages na branch principal.
4. Acessar a URL publicada.

## Observações

- Não usar `server.cjs` em produção.
- LocalStorage funciona no navegador.
- Não publicar automaticamente sem autorização.
